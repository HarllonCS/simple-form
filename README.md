# Registration Form in Pure HTML

A simple web project consisting of a registration form built exclusively with **HTML5**, without the use of CSS or JavaScript. The main objective is to practice semantic structuring and grouping of form fields.

## Form Structure

The form is organized into two main sections using the `<fieldset>` tag:

1. **Personal Data**:
   - **Name**: Text field for the user's full name.
   - **Email**: Field with native email format validation.
   - **Password**: Password field with hidden characters.

2. **Person Type**:
   - Selection to identify whether the registration is for an **Individual (CPF)** or a **Legal Entity (CNPJ / PJ)**.

## Tech Stack

- **HTML5**

## Getting Started

1. Clone this repository or download the files.
```bash
git clone https://github.com/HarllonCS/simple-form.git
```
2. Open the `index.html` file directly in any modern web browser (Chrome, Firefox, Edge, etc.).
